# HealthFit-Pro 🏃‍♀️🥗

HealthFit-Pro is an AI-powered nutrition and fitness backend built for LNMIIT Hackathon.

## Features
- Personalized diet plans based on age, weight, goals
- Allergy & diet preference handling
- Progress-based plan updates
- Scalable Node.js backend

## Tech Stack
- Node.js
- Express.js
- Notion Database
- AI-based nutrition logic
